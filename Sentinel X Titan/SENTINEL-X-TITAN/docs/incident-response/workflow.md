# Incident Response Workflow

1. Detect
2. Validate
3. Classify
4. Investigate
5. Correlate
6. Identify affected systems
7. Characterize source infrastructure
8. Determine attack path
9. Contain
10. Preserve evidence
11. Eradicate simulated compromise
12. Recover owned data/systems
13. Verify integrity
14. Return services
15. Produce report

No hack-back stage exists.
