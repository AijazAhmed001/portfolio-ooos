# Security Policy

SENTINEL-X TITAN is a defensive cyber-range and SOC simulation platform.

- Never point the simulator at networks you do not own or have explicit permission to test.
- Never use source attribution as proof of a person's identity or exact location.
- Never use the platform for hack-back, unauthorized access, credential theft, persistence or exfiltration against real systems.
- Keep cyber-range networks isolated from production networks.
- Use synthetic/demo data in destructive-impact scenarios.
